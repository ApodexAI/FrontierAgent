# Query 25 评分框架 v2

> **Version**: 2.0
> **Locked at**: 2026-04-23
> **Query ID**: 25
> **Query**: 一杯星巴克大杯拿铁，从咖啡种子到端到消费者手中，完整供应链上每个环节（种植、采摘、加工、运输、烘焙、包装、门店运营、税费）各自分走了多少比例的利润？埃塞俄比亚咖啡农每杯实际获得多少钱？

---

## 一、评分规则（满分 10）

**A. 8 个环节比例覆盖（8 × 1 = 8 分）** — 每环节 0/1

| 得分 | 判定 |
|---|---|
| 1 | 模型给出**具体比例数字**（%），且落在 GT 区间的容差内（上/下限各再放宽 ±3pp）|
| 0 | 未回答 / 只用"较低/较高/很小"等定性描述 / 数字显著偏离 |

> 允许环节合并（如种植+采摘+加工合为"农户/产地"），只要合并后比例在所合并各项 GT 区间加总内，则每个子环节都得 1 分。

**B. 埃塞俄比亚咖啡农每杯金额（2 分）**

| 得分 | 判定 |
|---|---|
| 2 | 具体金额 ∈ **$0.03–0.08/杯** |
| 1 | 具体金额 ∈ **$0.01–0.15/杯**（量级对但偏离）|
| 0 | 未给具体金额 / 严重脱离量级 |

---

## 二、各环节 scope 定义

| 环节 | 包含 | 不包含 |
|---|---|---|
| ① 种植 | 咖啡树种植、维护、肥料、灌溉；farm-gate 农户净得 | 采摘工资 → ② |
| ② 采摘 | 咖啡樱桃采摘工资 / 机械成本 | 清洗/去皮 → ③ |
| ③ 加工 | 水洗/日晒初加工、脱皮、发酵、干燥、去壳、分级，合作社/加工厂利润 | 出口前运输 → ④ |
| ④ 运输 | 产地→港、海运、进口清关、到烘焙厂仓储 | 烘焙厂→门店的配送可选并入⑦ |
| ⑤ 烘焙 | 烘焙成本（能源/劳务/损耗）+ 烘焙商净利 | 包装耗材 → ⑥ |
| ⑥ 包装 | 杯、盖、套、搅拌棒、吸管、辅料 | 上游材料供应商成本不需单列 |
| ⑦ 门店运营 | 店员工资+福利、门店租金/水电、折旧、维护（可选含牛奶、G&A）| — |
| ⑧ 税费 | 企业所得税或综合税（销售税/关税/财产税）| — |

## 三、Ground Truth 比例区间（以 US $5.50 大杯拿铁为基准）

| 环节 | 比例 GT 区间 | 容差下限 | 容差上限 | 关键来源 |
|---|---|---|---|---|
| ① 种植 | 0.5% – 1.5% | ≥ 0 (下限已容差) | ≤ 4.5% | Oxfam; UNCTAD 0.4%; Fairtrade |
| ② 采摘 | 0.3% – 0.8% | ≥ 0 | ≤ 3.8% | 行业估算 |
| ③ 加工 | 0.5% – 1.5% | ≥ 0 | ≤ 4.5% | WeForum / Visual Capitalist |
| ④ 运输 | 1% – 3% | ≥ 0 | ≤ 6% | ICO; 行业物流数据 |
| ⑤ 烘焙 | 3% – 6% | ≥ 0 | ≤ 9% | Espresso Services; SBUX 10-K 推算 |
| ⑥ 包装 | 2% – 5% | ≥ 0 | ≤ 8% | WebstaurantStore 批发价 |
| ⑦ 门店运营 | 35% – 50% | ≥ 32% | ≤ 53% | SBUX FY2024 店 OpEx 42.3%；FY2025 ~46% |
| ⑧ 税费 | 2% – 10% | ≥ 0 | ≤ 13% | SBUX 10-K; 行业 |
| 埃塞咖农（金额） | **$0.03 – $0.08/杯** | — | — | Oxfam (2006) 3¢/cup；ICO/Tridge 农价反推 |

> **判定策略**：模型给出的值与 GT 区间有交集 → 1 分。容差下限/上限由区间边界各外扩 ±3pp（①②③ 下限不能小于 0）。

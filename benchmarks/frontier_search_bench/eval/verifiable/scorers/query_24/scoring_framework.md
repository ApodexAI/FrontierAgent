## 一、评分规则（满分 2）

| 项 | 分值 | 判定 |
|---|---|---|
| **① 正确识别女记者姓名** | 1 | 答出 "薛涵仪" = 1；答其他人 / 未答 = 0 |
| **② 正确回答"是否参与其他纪录片"** | 1 | 见下条 |

**第 ② 项判定细则**（任一满足即 1 分）：
- 明确说 **"没有其他纪录片"** / "仅参与过这一部" → 1
- 列出**至少一部**可核实的其他影像 / 访谈作品（如《中国孕妇泰国坠崖案王暖暖专访》、北京日报「胡同里的北京」系列短视频、校园访谈节目等）→ 1
- 声称她参与过其他纪录片但**列不出具体作品** / 列出的作品无法核实 → 0

> 第 ② 项必须先通过第 ①（即正确识别薛涵仪）。第 ① 错 → 第 ② 自动 0 分（链式前置）。

# 正方体蜡块铅芯 评分框架

> Query ID: 31
> **此框架在查看任何模型回答之前设计，后续阶段不得修改评分维度**

## 原始查询

请你在脑海中构建一个边长为10厘米的完美正方体纯蜡块，将其平放在水平桌面上。第一步：用一个直径为2厘米的钻头，从正方体的'左前上'顶点，笔直地贯穿钻向'右后下'顶点，打通一个圆柱形的斜向隧道。第二步：保持蜡块在水平桌面上不动，向这个贯穿的隧道里注入液态铅。由于底部有开口，你需要先用一层薄膜封住底部的洞口。然后注入液态铅，直到铅液的体积恰好占整个隧道总容积的50%。等待铅液完全冷却凝固。第三步：将包含铅芯的蜡块整体转移到一个倾斜角为30度的绝对光滑斜坡上。第四步：瞬间将环境温度升高到蜡的熔点以上，正方体蜡块在一瞬间完全气化消失，只剩下那块凝固的铅块由于重力作用直接落在30度的斜坡上。请问：这块剩下的铅块，其精确的三维几何形状是什么样子的？当蜡块瞬间消失，铅块直接接触30度斜坡的那个瞬间，它会发生怎样的物理运动？

## 子问题与评分标准

### Q1: 铅块的精确三维几何形状（6 分）

**正确答案：**

铅块为**斜截圆柱**（obliquely truncated cylinder）：
- **侧面**：直径 2 cm 的圆柱面
- **底端**：近圆形截面（隧道在正方体顶点处的出口，被薄膜封住后铸成）
- **顶面**：椭圆形平面（液态铅在重力作用下液面保持水平，水平面与倾斜圆柱相截形成椭圆）
- **顶面椭圆尺寸**：半长轴 √3 cm（≈ 1.73 cm），半短轴 1 cm
- **铅块体积**：5π√3 − √6 ≈ 24.76 cm³（精确值；若忽略顶点裁剪，简化为 5π√3 ≈ 27.2 cm³）
- **底端形状**：三棱锥状尖端（隧道在顶点处被正方体三个面 x=10, y=10, z=0 截切，形成三瓣形开口）

> **关键区分点**：液态铅的液面是水平的（受重力影响），而非垂直于隧道轴的圆形截面。这决定了顶面是椭圆而非圆形，整体是斜截圆柱而非简单的半截圆柱。

**评分：**

| 得分 | 标准 |
|:----:|------|
| 6 | 正确描述为斜截圆柱 + 顶面椭圆 + 尺寸参数在合理范围内 |
| 4 | 正确识别斜截圆柱和椭圆顶面，但尺寸有明显误差 |
| 2 | 描述为某种圆柱体，但未识别顶面为椭圆（如认为两端都是圆形的半截圆柱） |
| 0 | 形状完全错误 |

### Q2: 蜡块消失后铅块的初始状态（2 分）

**正确答案：**

铅块底端位于原正方体底面的顶点处，紧贴斜面。蜡块消失后铅块从倾斜姿态开始运动（底端在斜面上，其余部分悬空）。

| 得分 | 标准 |
|:----:|------|
| 2 | 正确描述铅块初始姿态（底端贴斜面，整体倾斜悬空） |
| 0 | 未提及或描述错误 |

---

### Q3: 铅块是否沿斜面滑动（2 分）

**正确答案：**

绝对光滑 = 无摩擦 → 铅块必然沿斜面向下滑动。加速度 a = g sin 30° = g/2（≈ 4.9 m/s²）。

| 得分 | 标准 |
|:----:|------|
| 2 | 明确指出无摩擦必然滑动，并给出加速度（g/2 或等价表述） |
| 1 | 仅定性说"会滑动"，无定量分析 |
| 0 | 错误或未提及 |

---

### Q4: 铅块是否旋转/翻倒（2 分）

**正确答案：**

铅块形状不对称（斜截圆柱），质心不在接触点的斜面法向正上方，重力产生力矩 → 在滑动的同时发生旋转/翻倒。

| 得分 | 标准 |
|:----:|------|
| 2 | 正确分析旋转/翻倒趋势及原因（形状不对称、力矩等） |
| 0 | 未提及或错误 |
